# preview

## Nombre

preview — previsualiza el build de producción

## Sinopsis

```
just preview [--port 4173]
make man TARGET=preview
```

## Descripción

Ejecuta `make build` y sirve `dist/` con `vite preview`.

## Ejemplos

```bash
just preview
```
