# clean

## Nombre

clean — elimina artefactos generados

## Sinopsis

```
make clean
make man TARGET=clean
```

## Descripción

Borra `site/`, `MODULE/dist/` y `MODULE/coverage/` con los guardas de seguridad de `helpers/shell/clean.sh`.

## Ejemplos

```bash
make clean
```
