# test-unit

## Nombre

test-unit — ejecuta solo los tests unitarios

## Sinopsis

```
make test-unit
make man TARGET=test-unit
```

## Descripción

Vitest sobre `tests/unit/`. No usan red, sistema de archivos ni APIs del navegador.

## Ejemplos

```bash
make test-unit
```
