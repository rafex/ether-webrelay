# lint

## Nombre

lint — análisis estático con Biome

## Sinopsis

```
make lint
make man TARGET=lint
```

## Descripción

Ejecuta `biome check` (lint + formato + orden de imports) sobre el frontend. No modifica archivos.

## Ejemplos

```bash
make lint
```
